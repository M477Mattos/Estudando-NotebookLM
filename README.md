# Estudando-Desenho-NotebookLM
O Repositório guia de estudos de Desenho com auxilio do NotebookLM.

Este repositório tem o objetivo de servir como curso guiado pelo notebooklm para estudar e praticar desenho.
A ideia é servir principalmente para quem está no estágio zero, a ponto de nem mesmo saber segurar o lápis (situação mais comum do que parece).

Fontes usadas no notebooklm:
https://ricardoguchi.com.br/wp-content/uploads/2020/07/ebook_cad72020v1.pdf
https://cursodesenhetudo.com/wp-content/uploads/2021/06/FeKroJlTIg.pdf
https://ricardoguchi.com.br/wp-content/uploads/2020/07/ebook_cad72020v1.pdf
Uma quarta fonte existiu porém não consegui usá-la no projeto então não será necessária.

Prompts e resumo de suas respostas:
"Vamos criar uma curso de desenho desde completo zero até o realismo.
Então utilize todas as fontes para gerar um conteúdo com o máximo de informações e técnicas em ordem crescente de dificuldade e então seja o professor de artes que explicará cada conteúdo do curso.
Não resuma conteúdos explique o máximo sobre cada técnica para que seja didático para quem nunca desenhou."
Um prompt inicial que deixa tudo bem claro e o notebooklm responde muito bem a ele estruturando uma resposta gigante com 6 módulos dividos alguns tópicos, criando realmente uma progressão desde como segurar o lápis para traços e sombreados até técnicas avançadas de noções de visualização de cenário e iluminação realista.
Em seguida eu pedi uma rotina de treino usando o prompt sugerido pelo próprio notebook, a resposta foi boa até mas foi meio de 0 a 100 em um treino de meia hora, não fez muito sentido. 
Então eu criei um prompt em volta dessa ideia de cronograma de treino com exercícios para cada módulo do curso (Assim mesmo, simples e direto).
A resposta dessa vez foi incrível, realmente trazendo treinos de meia hora para cada módulo do curso, permitindo a progressão nos estudos guiados não só pelo material teórico mas agora com exercícios práticos.

Por fim explorei as funções do notebooklm de criação de slides e vídeo utilizando um prompt que pedia para usar o próprio curso já gerado como conteúdo, o que trouxe uma experiência visual para todo o conteúdo já visto algo que soma muito no aprendizado.

Com isso eu concluo o guia de desenhos com notebooklm, a minha experiência foi muito boa e eu pretendo aprender as técnicas no meu tempo livre, espero que ajude pessoas com vontade de aprender a desenhar não só a aprender a desenhar mas também a conhecer o notebooklm.
